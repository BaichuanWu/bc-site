# Color QUICK Alpha WQB IDs

## Why

The Alpha list and analysis table currently show a QUICK badge beside State. The simulation mode should be visible directly on the WQB ID without adding a separate column or badge.

## What Changes

Show the saved QUICK simulation mode through the WQB ID text: yellow for QUICK, normal styling for other modes. This changes presentation only; the API contract and FULL upgrade action stay the same.
